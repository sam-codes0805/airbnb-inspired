# Airbnb Clone

A full-stack Airbnb-inspired web application built while learning **Node.js, Express.js, MongoDB, and backend web development**.

The project allows users to explore property listings, view individual properties, create and manage listings, and interact with the application through a server-side rendered interface.

## 🚀 Features

* User authentication and authorization
* Create, view, edit, and delete property listings
* Property listing details and images
* MongoDB database integration
* Server-side rendering with EJS
* RESTful routing with Express.js
* Form validation and error handling
* Responsive user interface
* MVC-based project structure

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/sam-codes0805/airbnb-inspired.git
cd airbnb-inspired
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the root directory and add the required environment variables.

```env
MONGO_URL=your_mongodb_connection_string
```

Add any other variables required by the application.

### 4. Start the application

For development:

```bash
npm start
npm run tailwind
```

Or:

```bash
npm start
```

The application will be available at:

```text
http://localhost:5173
```
